## 🚀 How to Use These Files

### Development
```bash
# 1. Navigate to project
cd /vercel/share/v0-project

# 2. Install (already done)
pnpm install

# 3. Start dev server (already running on port 5173)
pnpm dev

# 4. Access at http://localhost:5173
```

### Customization

#### Change Colors
Edit `src/index.css` CSS variables

#### Add New Page
1. Create `src/pages/NewPage.jsx`
2. Add route in `src/App.jsx`
3. Add nav link in `src/components/Layout.jsx`

#### Connect Real API
Edit `src/hooks/useApi.js` to call real endpoints

#### Connect Real WebSocket
Edit `src/context/WebSocketContext.jsx` with real server

### Deployment
```bash
# Build for production
pnpm build

# Deploy dist/ folder
# To Vercel, Netlify, AWS, GitHub Pages, etc.
```
